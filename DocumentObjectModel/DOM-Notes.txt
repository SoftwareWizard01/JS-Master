Attribution Manipulation

HTML Code

<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Document</title>
  </head>
  <body>
    <a href="https://www.google.com"> Download Me </a>
    <h1 class="abcd">Hello Duniya</h1>
    <h1 class="abcd">Hello Duniya</h1>
  </body>
</html>

JS Code

get attribute

let a = document.querySelector("a");
a.getAttribute("href");                  -->Output:    https://www.google.com

set attribute

let h1 = document.querySelector("h1");
h1.setAttribute("href", "https://www.wikipedia.com");           --> Now the legacy code isn't changed but if we
                                                                    inspect in the browser for the code we can
                                                                    witness changes occured in the HTML


remove attribute

let a = document.querySelector("a");
a.removeAttribute("href");                --> this will remove the href attribute from the a tag

Append/Prepend


HTML Code

<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Document</title>
  </head>
  <body>
    <div>
      <h1 class="abcd">Hello Duniya</h1>
      <h1 class="abcd">Hello Duniya</h1>
      <h1 class="abcd">Hello Duniya</h1>
    </div>
  </body>
</html>


JS Code

Append

let h1 = document.querySelector("h1");
h1.textContent = "Hello Bhava Kasa Aahes";
document.querySelector("body").append(h1);     --> this will add the h1 tag at the end of the body tag

Output: Hello Duniya
        Hello Duniya
        Hello Duniya
        Hello Bhava Kasa Aahes



Prepend

let h1 = document.querySelector("h1");
h1.textContent = "Hello Bhava Kasa Aahes";
document.querySelector("body").prepend(h1);    --> this will add the h1 tag at the start of the body tag

Output: Hello Bhava Kasa Aahes
        Hello Duniya
        Hello Duniya
        Hello Duniya

JS Code

Let h1 = document.querySelector("h1");
body.remove("h1");     --> this will remove the h1 tag from the body tag and the output will be blank page




If you wanted to make changes in the CSS of the website using JS then we can do that by using style property of the element


let h1 = document.querySelector("h1");
h1.style.color = "red";     --> this will change the color of the text inside the h1 tag to red

you can also change the background color, font size, font family and many more CSS properties using the style property of the element

You can use add,remove and toggle method to add,remove and toggle the class of the element

let h1 = document.querySelector("h1");
h1.classList.add("new-class");     --> this will add the class "new-class" to the h1 tag

h1.classList.remove("abcd");     --> this will remove the class "abcd" from the h1 tag
h1.classList.toggle("new-class");     --> this will toggle the class "new-class" to the h1 tag if it is present then it will remove it and if it is not present then it will add it

toggle is used to add or remove the class based on the condition if the class is present then it will remove it and if it is not present then it will add it
For eg.:
let h1 = document.querySelector("h1");
h1.classList.toggle("new-class");     --> this will add the class "new-class" to the h1 tag
h1.classList.toggle("new-class");     --> this will remove the class "new-class" from the h1 tag
